# URBAN EXPRESS | System Version History

## [v2.5.0] - 2024-09-05
### Added
- **Mother Hub Architecture**: High-fidelity control centers for Intelligence, Staff, Finance, Logistics, and Governance.
- **Conversational UI**: Full system navigation transition to natural, professional English.
- **Mandatory Geofencing**: Hard-lock security modal restricting operations to the authorized workplace boundary.
- **Admin Bypass**: Automatic security modal exemption for administrative roles.
- **Batch Clearance Engine**: Mass purge and reconciliation tools for department backlog management.
- **High-Fidelity Assets**: Integrated `hero3.png` and `hero4.png` for a premium cinematic terminal experience.

### Changed
- **Streamlined Sidebar**: Reduced sidebar clutter by grouping 20+ modules into 5 strategic hubs.
- **Enlarged Clock Node**: Increased header clock size for better second-accurate shift tracking.
- **Redesigned Navigation Cards**: Minimalist, icon-free cards with high-contrast action buttons.
- **Notification Pill**: Enlarged and solidified red notification counter for improved readability.

### Security
- **GitHub Security Protocol**: Established official security reporting and system integrity documentation.
- **Vulnerability Disclosure**: Integrated `.github/SECURITY.md` for standardized risk reporting.

## [v2.4.0] - 2024-08-10
### Added
- **M-Pesa Manual Reconcile**: Added ability to finalize orders using transaction reference codes.
- **Departmental Recalls**: Unified list of held bills for Lounge, Store, and Carwash.
- **System Maintenance Hub**: Added historical stock synchronization tools.

## [v2.0.0] - 2024-07-15
### Added
- **Unified Business OS Core**: Migration to Next.js 15 App Router.
- **Multi-Unit POS**: Integrated Lounge, Retail, and Carwash into a single terminal logic.
- **Staff PIN System**: Secure terminal locking with 4-digit operator codes.
- **Paystack Integration**: Automated M-Pesa and Card authorization prompts.
