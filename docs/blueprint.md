# **App Name**: TradePilot

## Core Features:

- Real-Time Market Data: Fetch and display real-time market data for selected currency pairs.
- Interactive Charting: Display interactive charts with customizable timeframes (1h, 4h, 1d) to visualize market trends.
- Trading: Allow users to execute buy and sell orders with specified quantities.
- AI Technical Analyst: The application has an AI technical analyst tool, to provide market insights using price, strategy, and time frame to generate trade ideas
- Automated Trading Bot: Enable automated trading based on pre-defined strategies, allowing users to configure trade amount and interval.
- Wallet Management: Allow users to deposit and withdraw funds and displaying transaction history.
- Strategy Builder: Allow the user to define and configure strategies

## Style Guidelines:

- Primary color: Soft blue (#64B5F6) to convey trust and stability.
- Background color: Dark gray (#263238) for a modern, sophisticated feel.
- Accent color: Yellow (#FFC107) to highlight key interactive elements.
- Headline font: 'Space Grotesk' sans-serif, suitable for headlines and short amounts of body text; use 'Inter' for longer body text.
- Code font: 'Source Code Pro' for displaying code snippets and bot logs.
- Use clear, modern icons from a set like Lucide to represent different UI actions and data types.
- Subtle transitions and animations to enhance user experience and provide feedback on interactions.
