# UI/UX & Design System Specification

## 1. Design System: URBAN RED
- **Primary Color**: `hsl(0, 72.2%, 50.6%)` (Vibrant Red)
- **Background**: `hsl(0, 0%, 100%)` (Pure White)
- **Accents**: `hsl(0, 0%, 96.1%)` (Light Zinc)
- **Typography**: 
  - **Headlines**: Space Grotesk (Modern, Bold)
  - **Body/Data**: Inter (Highly legible, dense)

## 2. Component Standards
- **Buttons**: Rounded-md, high-contrast red for primary actions.
- **Tables**: Bordered zinc-200, zebra-striping for inventory lists.
- **Modals**: Centered, clean white background, red header accents.
- **POS Interface**: Large touch-friendly targets, high-visibility currency displays.

## 3. Responsive Behavior
- **Desktop**: Main administrative and management dashboards.
- **Tablet**: Primary POS interface for Lounge and Store.
- **Mobile**: Carwash attendant job tracking and supervisor quick-approvals.
